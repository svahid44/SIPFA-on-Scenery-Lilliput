# گزارش نهایی سناریوی ۳ SIPFA روی SCENERY-64/80

## ۱. هدف

سناریوی ۳ حالت «خطای پایدار معلوم + مقابله‌گر مبتنی بر infection» را بررسی می‌کند. محل logical S-box و ورودی خطا `delta` برای مهاجم معلوم‌اند، اما خروجی‌های مؤثر به بلوک‌های تصادفی ۶۴بیتی تبدیل می‌شوند. مهاجم فقط ciphertext عمومی را دریافت می‌کند و برچسب مؤثر/بی‌اثر منتشر نمی‌شود.

## ۲. مدل infection

برای هر پرس‌وجو، رمزنگاری صحیح و خطادار فقط داخل شبیه‌ساز محاسبه می‌شوند:

- اگر `C_correct == C_faulty` باشد، رخداد بی‌اثر است و `C_correct` منتشر می‌شود.
- اگر دو خروجی متفاوت باشند، رخداد مؤثر است و یک بلوک تصادفی مستقل منتشر می‌شود.

بنابراین هر پرس‌وجو دقیقاً یک خروجی عمومی دارد. dataset عمومی شامل فقط `sample_index,ciphertext` است و plaintext، برچسب رخداد، کلید، ciphertext صحیح/خطادار و بلوک infection را افشا نمی‌کند.

## ۳. نگاشت Algorithm 3

برای logical S-box شماره `j`، مقدار عمومی دور آخر از نیمه چپ ciphertext استخراج می‌شود. در رخدادهای بی‌اثر، مقدار

```text
minimum[j] = delta XOR SK28[j]
```

در داده صحیح ظاهر نمی‌شود؛ اما ciphertextهای تصادفی infection همه binها را با نویز تقریباً یکنواخت پر می‌کنند. در نتیجه مقدار هدف معمولاً غایب نیست، بلکه کم‌فراوان‌ترین bin می‌شود. بازیابی word به صورت زیر است:

```text
SK28[j] = minimum[j] XOR delta
```

این حمله برای هشت logical S-box در هشت کمپین مستقل تکرار و هشت word چهاربیتی به نمایش bitslice کلید دور تبدیل شدند.

## ۴. نتیجه کمپین ثابت

پارامتر کمپین مرجع:

```text
known delta              = 0x5
published per S-box      = 32768
total public outputs     = 262144
internal ineffective     = 43547
random infected outputs  = 218597
```

نرخ بی‌اثر:

```text
theoretical rate = 0.164132936375
empirical rate   = 0.166118621826
```

بازیابی کامل:

```text
Recovered words = [B,3,A,C,E,7,0,B]
Recovered SK28  = A3B7389D
Actual SK28     = A3B7389D
Result          = PASS
```

فاصله بین کمینه و دومین کمینه برای هشت S-box بین ۲۲۱ و ۳۸۲ شمارش بود و هر هشت histogram کمینه یکتا داشتند.

## ۵. آزمایش‌های تکرارشونده

برای ارزیابی آماری، ۱۰۰ اجرای مستقل انجام شد. در هر اجرا موارد زیر تازه و تصادفی بودند:

- کلید اصلی ۸۰بیتی؛
- مقدار چهار‌بیتی `delta`؛
- seed تولید plaintext و بلوک‌های infection؛
- هشت کمپین مستقل مربوط به هشت logical S-box.

شبکه نمونه برای هر S-box:

```text
512, 1024, 1536, 2048, 3072, 4096,
6144, 8192, 12288, 16384, 24576, 32768
```

| 512 | 4096 | 0% | 23.875% |
| 1024 | 8192 | 0% | 39.750% |

| 2048 | 16384 | 2% | 61.000% |

| 4096 | 32768 | 26% | 85.625% |

برای `100/100`، کران پایین فاصله Wilson نودوپنج درصد تقریباً `96.3%` است؛ بنابراین این عبارت به معنی تضمین ریاضی صددرصد نیست.

### آستانه‌های مشاهده‌شده

- حداقل ۵۰٪ موفقیت کامل: ۶۱۴۴ نمونه برای هر S-box؛
- حداقل ۸۰٪ و ۹۰٪: ۸۱۹۲ نمونه؛
- حداقل ۹۵٪ و ۹۹٪: ۱۶۳۸۴ نمونه؛
- `100/100` مشاهده‌شده: ۲۴۵۷۶ نمونه.

در بیشترین اندازه داده، تمام ۱۶ مقدار `delta` موجود در ۱۰۰ trial به بازیابی کامل منجر شدند. تعداد trialهای هر delta یکسان نبود و این جدول برای نشان‌دادن نبود bias آشکار در grid نهایی است، نه مقایسه آماری هم‌قدرت بین deltaها.

## ۶. رفتار minimum gap

با افزایش داده، فاصله کمینه هدف از دومین کمینه رشد کرد. میانگین gap کمپین‌ها تقریباً از `2.99` در ۵۱۲ نمونه به `278.57` در ۳۲۷۶۸ نمونه رسید. این معیار توضیح می‌دهد چرا حمله infection به داده بیشتری از سناریوی detection نیاز دارد: مقدار هدف صفر نیست و باید از نویز یکنواخت infection آماری تفکیک شود.

## ۷. مرز مهاجم و ground truth

حمله فقط از ciphertext عمومی، شماره S-box و `delta` معلوم استفاده می‌کند. کلید واقعی و شمارنده رخدادهای داخلی وارد تابع recovery نمی‌شوند. در ابزار آزمایش تکراری، ground truth صرفاً پس از بازیابی برای محاسبه نرخ موفقیت، نرخ بی‌اثر و صحت wordها استفاده می‌شود.

## ۸. نتیجه نهایی

Algorithm 3 روی SCENERY-64/80 قابل پیاده‌سازی است و با هشت کمپین مستقل، کل subkey دور آخر را بازیابی می‌کند. infection مقدار متمایز را حذف نمی‌کند، اما آن را از یک مقدار غایب به یک کمینه آماری تبدیل می‌کند. در ارزیابی ۱۰۰تکراری، ۱۶۳۸۴ خروجی عمومی برای هر S-box موفقیت `99%` و ۲۴۵۷۶ خروجی برای هر S-box موفقیت مشاهده‌شده `100/100` ایجاد کرد.

این سناریو در محدوده بازیابی `SK28` بسته شده است و ادعایی درباره بازیابی master key هشتادبیتی یا subkey دورهای قبل ندارد.
