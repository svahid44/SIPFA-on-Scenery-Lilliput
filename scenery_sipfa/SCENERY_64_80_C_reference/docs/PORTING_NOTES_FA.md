# یادداشت فنی انتقال SCENERY از Python به C

## 1. نمایش بلوک

بلوک هشت‌بایتی به صورت big-endian خوانده می‌شود:

```text
L1 = P0 || P1 || P2 || P3
R1 = P4 || P5 || P6 || P7
```

پس از 28 دور، خروجی مطابق الگوریتم مقاله با swap نهایی ساخته می‌شود:

```text
C = R29 || L29
```

## 2. رابطه دور

```text
R(i+1) = L(i)
L(i+1) = R(i) xor F(L(i), SK(i))
```

و:

```text
F(L,SK) = MixColumns(SubColumns(L xor SK))
```

## 3. SubColumns بیت‌اسلایس

کلمه 32 بیتی به چهار بایت `L0 || L1 || L2 || L3` تقسیم می‌شود. برای هر موقعیت بیت j:

```text
x = L0[j] + 2*L1[j] + 4*L2[j] + 8*L3[j]
y = S[x]
```

بیت صفر خروجی S-box به ردیف L0 و بیت سه به ردیف L3 برگردانده می‌شود. این ترتیب هر چهار بردار مقاله را بازتولید می‌کند.

## 4. MixColumns

```text
t   = ROL8(L1,1) xor ROR8(L0,3)
L0' = ROR8(L0,2) xor t
L1' = L1 xor t

z   = ROL8(L3,4) xor ROL8(L2,1)
L2' = L2 xor z
L3' = ROR8(L3,3) xor z
```

## 5. زمان‌بندی کلید

کلید اولیه ده بایت است و اولین subkey همان چهار بایت اول master key است. پس از استفاده از subkey دور i، این مراحل اجرا می‌شوند:

1. اعمال S-box روی `k12..k15` و `k28..k31`؛
2. چرخش چپ کل حالت 80 بیتی به اندازه 11 بیت؛
3. XOR ثابت پنج‌بیتی دور روی `k11..k15` حالت چرخیده؛
4. استخراج `v0=k14||k15` از حالت ورودی دور؛
5. چرخش چپ ده بایت میانی به اندازه `2*v0` بایت.

پیاده‌سازی C از آرایه ده‌بایتی استفاده می‌کند و به نوع غیرقابل‌حمل 128 بیتی وابسته نیست.

## 6. رمزگشایی

ساختار فایستل اجازه می‌دهد همان تابع رمزگذاری با round keyهای معکوس استفاده شود. ورودی ciphertext نیز به دو نیمه تقسیم و در پایان swap می‌شود.

## 7. ایمنی سطح C

- load/store دستی و مستقل از endianness میزبان؛
- عملیات in-place پشتیبانی می‌شود؛
- بررسی با AddressSanitizer و UndefinedBehaviorSanitizer؛
- build بدون warning با GCC و Clang؛
- C99 و بدون وابستگی خارجی.
