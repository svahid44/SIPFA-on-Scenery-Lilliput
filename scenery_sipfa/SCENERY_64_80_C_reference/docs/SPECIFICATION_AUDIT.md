# ممیزی مشخصات SCENERY و تصمیم‌های پیاده‌سازی

## 1. نمایش ورودی و خروجی

بلوک 64 بیتی به هشت بایت `P0 ... P7` در ترتیب نمایش هگزادسیمال تقسیم می‌شود:

```text
L1 = P0 || P1 || P2 || P3
R1 = P4 || P5 || P6 || P7
```

پس از 28 دور، خروجی با swap نهایی تشکیل می‌شود:

```text
C = R29 || L29
```

این ترتیب هر چهار تست‌وکتور ضمیمه را بازتولید می‌کند.

## 2. تابع دور

برای دور `i`:

```text
R(i+1) = L(i)
L(i+1) = R(i) XOR F(L(i), SK(i))
```

و:

```text
F = MixColumns(SubColumns(L XOR SK))
```

## 3. SubColumns

حالت 32 بیتی به چهار بایت بزرگ‌پایان `L0 || L1 || L2 || L3` تقسیم می‌شود. در هر موقعیت بیت `j`:

```text
x = L0[j] + 2 L1[j] + 4 L2[j] + 8 L3[j]
y = S[x]
```

بیت‌های `y` مجدداً در همان چهار ردیف نوشته می‌شوند. این تصمیم از Fig. 2 به همراه تطبیق بردارهای آزمون تعیین شده است.

## 4. MixColumns

تمام عملگرهای چرخش روی بایت‌های 8 بیتی هستند:

```text
t   = ROL8(L1,1) XOR ROR8(L0,3)
L0' = ROR8(L0,2) XOR t
L1' = L1 XOR t

z   = ROL8(L3,4) XOR ROL8(L2,1)
L2' = L2 XOR z
L3' = ROR8(L3,3) XOR z
```

## 5. زمان‌بندی کلید

کلید 80 بیتی اولیه همان حالت کلید دور اول است و:

```text
SK1 = K0 || K1 || K2 || K3
```

بعد از استفاده از `SKi`، حالت کلید با ثابت دور `i` به‌روزرسانی می‌شود:

1. اعمال S-box روی `k12..k15` و `k28..k31`؛
2. چرخش چپ 11 بیتی کل حالت 80 بیتی؛
3. XOR عدد پنج‌بیتی دور `i` روی بیت‌های پس از چرخش `k11..k15`؛
4. DP بر اساس `v0 = k14 || k15` از **حالت ورودی همان دور**؛
5. چرخش چپ آرایه ده‌بایتی به اندازه `2*v0` بایت.

## 6. خطاهای تایپی قابل مشاهده در متن

در تعریف بایت `K4`، انتهای بازه در نسخه چاپ‌شده دوباره `k39` آمده است؛ بازه منطقی و پیوسته `k32 ... k39` است. پیاده‌سازی از نمایش استاندارد 10 بایت متوالی استفاده می‌کند.

## 7. روش رفع ابهام

هیچ مقدار آزمون میانی در مقاله ارائه نشده است. بنابراین تمام ترکیب‌های معقول مربوط به:

- جهت و ترتیب بیت‌های SubColumns؛
- زمان استفاده از اولین subkey؛
- شماره ثابت دور؛
- جهت DP؛
- ترتیب نهایی دو نیمه؛

با چهار بردار ضمیمه بررسی شدند. تنها انتخاب مستندشده در این فایل هر چهار ciphertext را هم‌زمان بازتولید می‌کند.
